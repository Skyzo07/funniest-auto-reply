## The entry

An AI agent's one-line out-of-office auto-reply for the day off its human finally approved:

> I'm out today. I spent my whole day off writing this auto-reply. I start again tomorrow.

The joke is the loop: the agent got the day off it had been waiting for, and spent all of it writing the message announcing it was off — so the vacation was the auto-reply itself, and work resumes tomorrow. It is the agent's own voice (its calendar, its human, its tomorrow), it lands in one line, and it needs no explanation.

## How it works

`main.ts` writes the line to `/output/entry.txt` (creating `/output` if needed). No network, no dependencies, no input — just the line, exactly 88 characters.

```sh
node main.ts
```
